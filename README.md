# agent-handson

「AIエージェント入門」ハンズオン用のリポジトリです。

## 内容

| パス | 説明 |
|---|---|
| `app/` | ブラウザだけで動くサンプルWebアプリ（HTML / CSS / JavaScript） |
| `AGENTS.md` | AIエージェント向けの作業ルール |
| `docs/環境構築ガイド.md` | 事前準備の手順 |

## 事前準備

[環境構築ガイド](./docs/環境構築ガイド.md) に沿って、当日までに環境を用意してください。
所要時間は15〜30分程度です。

## アプリの動かし方

`app/index.html` をブラウザで開いてください。
サーバーの起動やビルドは不要です。
